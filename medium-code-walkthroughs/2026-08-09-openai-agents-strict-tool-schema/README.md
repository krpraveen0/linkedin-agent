# The OpenAI Agents SDK marks your optional tool parameters as required

Code for the 2026-08-09 Medium article. Demonstrates that `@function_tool` in the
[OpenAI Agents SDK](https://openai.github.io/openai-agents-python/) emits **strict**
JSON schemas by default, which forces every parameter — including ones with Python
defaults — into the schema's `required` list.

No API key and no network call are needed: building a `FunctionTool` and reading
`.params_json_schema` is a pure, local operation.

## What to notice

- **[1]** Under the default strict schema, all four parameters are `required` even
  though `max_price` and `nonstop` have Python defaults, and `additionalProperties`
  is `false`.
- **[2]** `@function_tool(strict_mode=False)` restores ordinary pydantic behavior:
  only the two parameters without defaults are `required`, and `additionalProperties`
  is dropped.
- **[3]** To make a parameter genuinely optional to the model under strict mode, use
  a nullable type (`Optional[str]`). The parameter stays in `required`, but its type
  becomes `anyOf: [string, null]`, so the model can satisfy it by sending `null`.
