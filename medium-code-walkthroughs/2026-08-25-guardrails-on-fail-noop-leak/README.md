## The point

A Guardrails `ValidationOutcome` carries two independent signals: `validation_passed` (the verdict) and `validated_output` (the value). They can disagree. The `on_fail` action decides what `validated_output` contains on failure:

- `exception` (the **default**, per `validator_base.py`: `if on_fail is None: on_fail = OnFailAction.EXCEPTION`) and the default raise.
- `fix` returns a safe replacement (`fix_value`).
- `filter` / `refrain` return `None`.
- `noop` returns the **original unsafe value** while setting `validation_passed = False`.

If you use `on_fail="noop"` and read only `validated_output`, you ship exactly the content you were validating against. Always check `validation_passed` when you use `noop`.
